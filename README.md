# Hotel Booking Website

A multi-page frontend web application interface designed for the hospitality industry, allowing users to browse rooms, check services, and navigate booking workflows.

Demo Link: [Live Preview](https://raza-rk1.github.io/hotel-booking/)

## 🛠️ Key Pages Included
- **Home (index.html):** Main landing page with featured rooms and service overviews.
- **Rooms (rooms.html & room-single.html):** Grid layout for browsing accommodations and a detailed view for specific rooms.
- **Services & About:** Structural pages showcasing amenities and corporate info.
- **Authentication:** Clean layout forms for User Login and Registration.

## 💻 Technologies Used
- HTML5
- CSS3 & SCSS (Structured Styling)
- JavaScript (ES6+)
